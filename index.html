Ask about my work

What agents has he built?

Three, all in production at 10x Productivity.

Charlie is Archer's strategy agent, built on Claude. It uses tools, loads skills on demand, gathers evidence in parallel, recalls earlier sessions and leans on prompt caching to keep cost down. The same tools sit behind an OAuth 2.1 MCP server, so the team can use them from Claude or Cursor too.

The other two are workflow agents: a Meta lead-ads agent that sizes ad sets from the budget and drafts on-brand ads, and a media-buyer agent that recommends what to change in an account.

How does he keep agents honest?

Mostly by not trusting them with the last step.

Nothing the lead-ads agent drafts goes live until a person approves the launch. The media-buyer agent's recommendations are checked against figures computed in SQL, never numbers the model made up, and a second critic model reviews them before anyone sees them.

Before an ad launches, Creative X-Ray scores it against the brand's own guidelines and lists what to fix.

What has he done with MCP?

Two MCP servers, both behind OAuth.

At 10x Productivity, an OAuth 2.1 MCP server exposes the same tools Charlie uses, so Claude and Cursor can work with Archer's knowledge directly.

On the side, Letterport gives AI agents their own email inboxes and ships a hosted MCP server, so agents can use their inbox as a tool.

What's underneath Archer?

  1. SourcesMeta Marketing API, Ad Library, AppMagic

Ingestion pulls from the Meta Marketing API, Ad Library and AppMagic for 100+ competitor brands, without a single client-specific pipeline. Every LLM call, across 60+ call sites, is attributed to a tenant and a feature, so cost is visible per client.

It all runs on 7 ECS Fargate services, provisioned with Terraform and deployed through OIDC CI/CD. He designed it and owns it end to end.

Did any of it move the business?

  • In a brand pilot, strategists accepted 85% of the AI-generated creative briefs they reviewed.
  • The multimodal analysis has run on 15k+ ads, breaking video into scenes and scoring 100+ signals.
  • At BIK.AI he halved the Elasticsearch bill at 300M events a month, cut deploy time by 40%, and was named Best Employee of the Quarter in April 2025.
  • At BLKBOX.AI he went from SDE-1 to SDE-3 in under 2.5 years.

What does he build on the side?

Wellread shows a business what ChatGPT and Gemini tell its buyers. It asks the questions buyers ask, with web search on, finds which brands get recommended and drafts the pages that would close the gap. 30+ early users so far.

Letterport is email for AI agents: inbound mail as clean JSON with header-based threading, a per-recipient delivery trail, signed webhooks and a hosted MCP server. Built with NestJS, AWS SES, SQS and CDK.

RapidMock lets frontend teams mock API responses without waiting on the backend.
